# private 账号仍记录可见的元信息

`status=private` 的含义是"内容不对未登录访客公开"，**不是"这个人没有元信息"**。实践中私密账号的昵称、bio、粉丝数往往仍在主页上可见，因此约定：这些字段只要能公开取到就照常填，取不到才为 null。把私密账号一律清空会同时丢掉真实数据并让覆盖率失真，而覆盖率与状态分类合计 40 分。

## Considered Options

- **填可见字段（采纳）**：数据最完整；代价是同一状态下的字段完整度不一致，需要靠 null 而非状态来判断"有没有"。
- **私密一律 null**：规则整齐，但白丢真实公开数据，且与"私密主页仍显示昵称与粉丝数"的事实冲突。
- **并入 not_found**：直接错分状态，违反五态要求，且会让失败统计虚高。

## Consequences

- 覆盖率统计按字段是否为非 null 计算，`private` 记录会被计入 bio / follower 的覆盖。
- 抽样复核时，`private` 记录同样要能与页面内容对上，不能以"反正私密"为由跳过。
- 若某平台对私密账号隐藏全部字段，则自然退化为 null，无需改动代码或规则。
