# 语言判定主线离线，大模型只作为可选增强

题面明确允许用大模型判定语言，但本项目把**默认路径**定为离线、确定性的规则判定（脚本字符集 + 停用词 + 文本长度阈值），理由不是"AI 不好"，而是：语言结果必须可复现、可解释、可离线测——同一份快照重跑必须得到同一个 `language`，否则"可审计"与"可重放"这两条同时失效。模型判定作为可选增强保留，一旦启用，必须把模型名、版本与输入文本片段一起写进 `language_evidence`。

## Considered Options

- **默认规则 + 可选模型（采纳）**：零网络、零成本、逐字节可复现；代价是短文本（如 3 个英文单词的 bio）容易被判成 `und`。
- **默认模型**：短文本准确率更高，但每次重跑结论可能漂移，且 100 条要付出 100 次调用成本与延迟。
- **模型 + 结果缓存**：能复现，但缓存的是"结论"而非"证据"，一旦模型下线就无法重新解释（参见 ADR-0005 的同一条理由）。

## Consequences

- `und` 会偏多。这是刻意的：题面要求"证据不足返回 und，不得编造"，宁可少判不可错判。
- 启用模型属于**显式的质量升级**，需要在 README 与 `AI_USAGE.md` 中说明使用范围、成本与校验方式。
- 判定器不得访问网络、时钟或随机数，否则重放测试失效。
